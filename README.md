# AngebotsPilot v10.8 – Compact UX & Rabatt

Neu:
- Wetterkarte auf „Heute“ deutlich kompakter; die ganze Karte öffnet die Wetteransicht.
- Baustellen-, Foto- und Dokument-Zähler in der Kundenakte sind direkt klickbar.
- Separates Anfahrtsfeld aus Angebot und Rechnung entfernt.
- Anfahrt wird ausschließlich als normale Position verwendet.
- Alte gespeicherte Anfahrtsbeträge werden automatisch in die Position „Anfahrt“ umgewandelt.
- Rabatt kann wahlweise in Euro oder Prozent eingegeben werden.
- Angebot und Rechnung zeigen Prozent-Rabatte sauber im Dokument an.
- Rechnungen aus Angeboten übernehmen Rabattart und Rabattwert.
- Rabatt wird vor der Umsatzsteuer berechnet.
