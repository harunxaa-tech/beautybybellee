# Digitaler Handwerker v9.5 – Angebot vereinfacht

## Neu
- Angebotsformular auf 3 klare Schritte reduziert: Kunde → Auftrag → Positionen
- Datum und Status standardmäßig automatisch vorbelegt
- Anfahrt, Rabatt und weitere Angaben eingeklappt
- modernere, einheitliche Eingabefelder
- + Button im Positionskatalog repariert
- neue Position erscheint sofort sichtbar im Angebot
- Katalogkarten für lange Namen repariert
- Terrassenreinigung und andere lange Bezeichnungen überschreiben keine Preise mehr
- auf kleinen iPhones wandert der Preis unter den Namen statt daneben
- Positionen können direkt im Angebot bearbeitet oder gelöscht werden

Alle bisherigen Funktionen bleiben erhalten.
