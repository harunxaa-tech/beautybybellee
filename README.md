# AngebotsPilot v10.0 – VERKNÜPFT

Neu:
- Kalendertag antippen → Termin direkt für diesen Tag anlegen
- Kunde in Termin/Baustelle auswählen → Adresse automatisch übernehmen
- Baustelle aus Kundenakte → Kunde + Adresse automatisch gesetzt
- Wenn genau ein angenommenes Angebot vorliegt, wird es für die Baustelle automatisch vorgeschlagen
- Angenommenes Angebot kann Baustellenname, Kunde, Adresse und Notiz vorfüllen
- Baustelle speichern → Kalendereintrag automatisch erstellen/aktualisieren
- Verknüpfter Termin kann Datum/Adresse der Baustelle aktualisieren
- Beim ersten Start wird der echte Vorname abgefragt
- Bestehende Installationen bekommen einmalig eine kurze Namensabfrage

Alles bleibt lokal und kostenlos. Cloud-/Mehrgeräte-Synchronisierung folgt später mit Backend.
