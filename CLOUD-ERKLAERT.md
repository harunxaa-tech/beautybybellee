# Cloud einfach erklärt

Bisher:
iPhone -> lokaler Browser-Speicher

v11.0:
iPhone -> Anmeldung bei Supabase
       -> Benutzerkonto
       -> Firmenkonto
       -> echte Rolle (Chef)
Geschäftsdaten bleiben vorerst lokal.

Nächster Schritt:
iPhone -> Anmeldung -> Firma -> Kunden / Angebote / Baustellen / Rechnungen in Supabase

Warum zweistufig?
Damit vorhandene Testdaten nicht ungeprüft in die falsche Firma geschrieben werden und damit wir die Beziehungen zwischen Kunde, Angebot, Baustelle und Rechnung sauber übertragen können.
