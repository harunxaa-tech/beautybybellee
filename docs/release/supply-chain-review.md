# Supply-chain review — 2026-11-25
- Native archive v0.6.0 contains native/package.json but no package-lock.json. Existing iOS/Codemagic workflows use npm install. Root package.json is a legacy manifest, not the actual packaged native source.
- App HTML loads Supabase JS @2.105.0 through jsDelivr without SRI. Pinning a version alone does not establish artifact integrity. Plan a vetted local bundle or verified SRI, CSP and offline/startup tests before release; do not invent a checksum.
- New read-only dependency audit job resolves a candidate lock with lifecycle scripts disabled, checks registry origin and SHA-512 integrity, uploads candidate lock and runs npm audit. No signing credentials or production deploy. Candidate must be reviewed, committed and used with npm ci; audit and lock do not detect all malware. Existing smoke/signed workflows have not yet been converted; release remains blocked until lock and clean audited build are verified.
- Static CI adds targeted secret-pattern scan of tracked text and zip text, including old archives, with redacted findings and tests. Public Supabase anon JWT is not a privileged key. Scan does not cover entire Git history, arbitrary binary formats, every secret syntax or deployed provider settings. Full history and external code scan remain open. If a real secret is found, rotate/revoke it before remediation; never print or repost it.
- Existing workflow action references are full SHA. Static checkout now does not persist credentials. Review actual install scripts and native CocoaPods/Gradle resolution separately. No auto-upgrades or paid services.
